# 任務：降低高重疊資料的過度保守復原

## 成功條件
- [x] 不使用固定奇偶刪除；仍依每條航帶的實際幾何重疊率自適應取樣。
- [x] 前向與旁向最低重疊率仍由設定值控制，試驗設定維持 70%。
- [x] 只有刪除造成原本有效的旁向配對消失時才復原照片；原始旁向不確定不再撤銷整條航帶的安全前向減量。
- [x] DSM 粗糙、缺值、轉彎與幾何不確定照片仍維持保留。
- [x] 這組 804 張資料的減量率明顯高於既有 10.4%，並報告與航帶內隔張基準的差異。
- [x] 自動測試、報告一致性與程式碼審查通過。

## 步驟
- [x] Step 1：確認基線測試、現行報告與過度復原來源。
- [x] Step 2：先新增原始旁向不確定與刪除破壞配對的行為測試，確認測試先失敗。
- [x] Step 3：以最小修改區分原始缺口與刪除造成的缺口。
- [x] Step 4：補齊摘要欄位／說明，並執行完整測試。
- [x] Step 5：對 804 張實際資料重跑，製作航帶內隔張基準並比較結果。
- [x] Step 6：執行程式碼審查、修正問題並完成驗證。

## 注意事項
- 不刪除或覆寫來源照片；所有結果僅產生清單與報告。
- 20 m DSM 高度仍是未確認垂直基準的試驗估計，不宣稱為真實 AGL。
- 不以本組資料的隔張可建模經驗推廣成其他任務的固定策略。
